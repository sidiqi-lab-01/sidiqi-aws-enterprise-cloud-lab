## Documentation Standard

Each command entry should explain:

1. Purpose
2. Prerequisites
3. Syntax
4. Parameters
5. Example
6. Expected result
7. Validation
8. Security considerations
9. Common errors
10. Troubleshooting

## Security

Never place passwords, private keys, access keys, secret keys, session
tokens, GitHub tokens, kubeconfig credentials, or other secrets in this
documentation.
